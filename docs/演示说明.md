# 5 分钟演示说明

> 适用版本：`v0.1.0` 验收基线。演示前请确保 `.env` 中的 PostgreSQL 可连接。
> `run_all.py` 默认以确定性模式启动（`LLM_ENABLED=false`），保证每次演示结果一致；需要展示 LLM 补抽时使用 `--llm`。

## 1. 准备（一次性，约 2 分钟）

```powershell
uv sync --extra parsing --extra dev --extra mcp
uv run python scripts/init_db.py          # 建表/迁移（幂等）
uv run python scripts/seed_rules.py       # 11 条规则
uv run python scripts/generate_samples.py # 4 份示例合同（docx/pdf/png）
```

## 2. 启动服务

```powershell
uv run python scripts/run_all.py
```

启动成功后可访问：

- Web 控制台：<http://127.0.0.1:8000/console>
- API 文档：<http://127.0.0.1:8000/docs>
- 健康检查：<http://127.0.0.1:8000/api/health>（应为 `{"status":"ok","db":"ok"}`）

## 3. 5 分钟演示流程

| 时间 | 操作 | 预期结果 |
|---|---|---|
| 0:00 | 打开 `/console`，点击「拉取待办」 | 列表出现 4 条审批单（AP20261021001 ~ 004） |
| 0:30 | 点击 AP20261021001「处理」 | 详情页自动刷新至「已完成 / 已回写」；解析页字段与证据完整；结果页总体风险【低】，Mock 评论区 1 条评论 |
| 1:30 | 返回列表，处理 AP20261021002（高风险 PDF） | 已完成；命中 6 条规则（R001/R002/R003/R004/R005/R011），总体风险【高】 |
| 2:30 | 处理 AP20261021003（扫描件） | 解析页显示 `ocr_used=true`；命中 4 条（R007/R008/R009/R010） |
| 3:15 | 处理 AP20261021004（缺附件） | 任务进入 `blocked / download / ATTACHMENT_MISSING`（红色徽章） |
| 3:45 | 故障注入页：模式 `missing_attachment`、限定 AP20261021002；重置演示数据后处理 AP20261021002 → blocked；清除故障 → 点「重试」 | `blocked` → 重试后 `done / success`，`retry_count=1` |
| 4:30 | 结果页再次点击「回写审批评论」 | 提示幂等重放，Mock 评论区仍为 1 条 |
| 4:45 | 终端执行 `uv run python scripts/demo.py` | 17/17 断言通过，生成 `demo_report.json` |

## 4. 验收证据（可选，1 分钟）

```powershell
uv run pytest -q                 # 72 passed
uv run python scripts/demo.py    # 17/17，输出 demo_report.json
```

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 拉取待办返回 502 / 连接失败 | 确认 Mock 审批系统已启动；本机开启系统代理时优先用 `run_all.py`（已自动设置 `NO_PROXY=127.0.0.1,localhost`） |
| 健康检查 `db=error` 或超时 | 检查 `.env` 的 `DATABASE_URL` 与 PostgreSQL 连通：`uv run python scripts/check_pg.py` |
| 端口 8000/8100 被占用 | 修改 `.env` 中 `APP_PORT` / `MOCK_PORT`，或关闭占用进程 |
| 规则命中为空 | 先执行 `uv run python scripts/seed_rules.py` |
| 需要 LLM 补抽 | `uv run python scripts/run_all.py --llm`（需在 `.env` 配置网关与 Key） |

## 6. 演示后重置

```powershell
uv run python scripts/reset_demo.py   # 清空任务/评论/附件，保留 11 条规则
```
